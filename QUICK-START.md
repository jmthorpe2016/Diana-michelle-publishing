## ⚡ To Start Accepting Real Payments (10 minutes)

### 1️⃣ Create Stripe Account
- Go to: [stripe.com](https://stripe.com)
- Sign up (free)
- Verify your email

### 2️⃣ Get Your API Key
- Login to [dashboard.stripe.com](https://dashboard.stripe.com)
- Click "Developers" → "API keys"
- Copy your **Publishable key** (starts with `pk_test_...`)

### 3️⃣ Add Key to Website
- Open: `diana-michelle-script.js`
- Line 150: Replace `pk_test_YOUR_KEY_HERE` with your actual key
- Save file

### 4️⃣ Deploy
```bash
cd /Users/jazsmine/CascadeProjects/windsurf-project
git add .
git commit -m "Add Stripe key"
git push
```

**Done! Your website is now accepting real payments!** 💳
